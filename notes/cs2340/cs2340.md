## GT Movies Store
We designed a web app allowing users to view movies, manage orders and reviews, with an admin portal such that administrators can manage all the web app data.

Created the following pages:
- **Home** (`/`): hero banner with store name and tagline.
- **About** (`/about`): description of the store's purpose.
- **Sign Up** (`/accounts/signup`): Django `UserCreationForm` in a card, errors shown as Bootstrap alerts.
- **Login** (`/accounts/login/`): username/password form, generic error message on failure.
- **Movie list** (`/movies/`): responsive poster grid and a title search box.
- **Movie detail** (`/movies/<id>/`): description, price, quantity + Add to cart, review list, review form.
- **Edit review** (`/movies/<id>/review/<rid>/edit/`): pre-filled textarea to update your own review.
- **Cart** (`/cart/`): table of items with prices, quantities, total, Purchase and Clear buttons.
- **Confirmation** (`/cart/purchase/`): "Purchase Completed" with the order number.
- **My Orders** (`/accounts/orders/`): one card per past order, with an item table.
- **Admin** (`/admin/`): Django admin for users, movies, reviews, orders, items.

The project had several user story requirements, which were all implemented through various screens. For each user story, criteria were met via:
1. Learn about the store: home + About page, both linked from the navbar and footer.
2. Register: signup page using `CustomUserCreationForm`, redirects to login on success.
3. Log in: login page; navbar then shows Orders and "Logout (username)".
4. View movie list: `/movies/` grid of poster cards, no login needed.
5. Search by title: GET form $\rightarrow$ `Movie.objects.filter(name__icontains=search_term)`.
6. Access a cart: `/cart/` table driven by a session dict, linked from every page.
7. Add one or more items: POST form on the detail page with a quantity input (1–10).
8. Create reviews: `@login_required` review form on the detail page with author set from `request.user`.
9. Empty the cart: "Remove all movies from Cart" resets the session cart.
10. Edit reviews: edit page, view rejects the request if `request.user != review.user`.
11. Delete reviews: ownership folded into the lookup using `get_object_or_404(Review, id=..., user=request.user)`.
12. See a movie's reviews: review list sits on the detail page, next to the price and Add to cart.
13. See movie details: name, description, price, poster.
14. See my orders: `request.user.order_set.all()` 
15. Use from any browser: plain server-rendered HTML servable from any browser
16. Responsive GUI: viewport meta tag, collapsing `navbar-expand-lg`, grid tiers `col-md-4 col-lg-3`, footer hidden on phones.
17. Admin: manage users: Django's built-in `auth` admin.
18. Admin: manage movies: `MovieAdmin` with `ordering=['name']` and `search_fields=['name']`.
19. Admin: manage reviews: `Review` registered in the admin.
20. Admin: manage orders: `Order` and `Item` registered in the admin.
21. Report reviews: Report button on other users' reviews removes the review from the page.
